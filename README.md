# BetaLaunch AI

Autonomous multi-agent AI squad that ingests raw business documentation into structured compliance knowledge bases and transforms product landing pages into ready-to-ship Product Hunt launch collateral.

## Features
- **Compliance Knowledge Base** — Auto-fills enterprise security questionnaires across 4 pillars
- **Product Hunt Launch Kit** — Hyper-optimized launch collateral in under 30 minutes

## Tech Stack
Vite + React, served on port 3000.
